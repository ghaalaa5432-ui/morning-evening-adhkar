# موقع أذكار الصباح والمساء

موقع ثابت (HTML واحد) لأذكار الصباح والمساء الصحيحة بمصادرها، مع:
- تكبير / تصغير الخط
- وضع ليلي / نهاري (dark / light)
- خط ثمانية (Thmanyah Sans / Serif Display / Serif Text)
- مسبحة إلكترونية لكل ذكر متعدد مع حفظ التقدم

## التشغيل محلياً
افتح ملف `index.html` في المتصفح مباشرة.

## النشر عبر GitHub Pages
1. ارفع `index.html` (وملف `README.md` اختياري) إلى مستودع باسم `morning-evening-adhkar`.
2. من صفحة المستودع: `Settings` ← `Pages`.
3. تحت `Build and deployment` اختر:
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)` ثم `Save`.
4. بعد دقيقة سيظهر الرابط:
   `https://USERNAME.github.io/morning-evening-adhkar/`

## المصادر
اعتمد الجمع على صحيح البخاري ومسلم، سنن أبي داود والترمذي والنسائي وابن ماجه، مسند أحمد، وتصحيحات الألباني. كل بطاقة تذكر مصدرها.
